# Desktop Portfolio

A desktop-inspired portfolio with a built-in music player.

This website is a small personal project where you can find some information about me, view my projects, and get my contact details. I also wanted it to feel more interactive than a regular portfolio, so the interface is designed to look and behave a little like a desktop environment.

I will add more features and content in the future.

## Features

- Desktop-inspired interface
- Draggable windows
- About, Projects, and Contact sections
- Built-in music player
- Light and dark themes
- Sound effects
- Mobile version (might look weird on some devices)

## Built With

- HTML
- CSS
- JavaScript

The project was built without frameworks or external JavaScript libraries.

## Overview

The website currently only has 3 windows: about, projects and a contact window. In the future I want to add more windows, for example links window and a downloadable CV.

There are also light/dark themes and a built-in music player. I tried to make it as functional as I could.

On smaller screens, the layout changes to make the interface more suitable for mobile devices.

## Current Limitations

- The website may behave slightly differently across browsers.
- Some desktop interactions are simplified on mobile devices.
- More content and projects will be added later.
- The current music will be replaced in a future version.
